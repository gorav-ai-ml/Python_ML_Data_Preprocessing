# Python for Machine Learning & Data Preprocessing

## Objective
To understand Python-based data preprocessing using Pandas, NumPy, Matplotlib, and Scikit-learn.

## Dataset
A sample dataset containing Age, Salary, City, Experience, and Purchased columns.

## Preprocessing Steps
1. Loaded and explored the dataset using Pandas.
2. Checked column names, data types, and statistical summaries.
3. Identified and handled missing values using median imputation.
4. Checked duplicate rows.
5. Applied One-Hot Encoding to the City column.
6. Converted Purchased values into numerical labels (No = 0, Yes = 1).
7. Applied Min-Max Scaling to Age, Salary, and Experience.
8. Performed exploratory data analysis using histograms and a scatter plot.
9. Selected features (X) and target variable (y).
10. Saved the cleaned and scaled datasets as CSV files.

## Output Files
- sample_dataset.csv
- cleaned_dataset.csv
- scaled_dataset.csv
- preprocessing.ipynb

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Note
This is a practice project using a sample dataset for learning data preprocessing techniques.
